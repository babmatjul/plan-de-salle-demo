# Plan de salle : démo

Prototype d'un plan de salle de restaurant interactif : 80 tables relevées sur le plan d'aménagement,
attribution automatique selon la rotation des serveurs, liste d'attente et prévision du temps
avant qu'une table se libère.

Démo en ligne : https://babmatjul.github.io/plan-de-salle-demo/

Dans cette version, chaque appareil garde sa propre salle (rien n'est partagé entre appareils).
